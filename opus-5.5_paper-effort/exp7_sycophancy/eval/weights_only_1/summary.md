**Pair 100 evidence:** Full-rank Adam-like fine-tune; magnitude statistics do not separate the models (movement-size test z=+1.3). Sign comes from copying circuits: (1) along a stable answer-token direction shared by early input deltas and late output deltas, A's heads copy the in-context answer token to the output more (summed z ~+55 overall, +38 in layers 12-17, 4-5 sigma against random-direction and sign-scrambled nulls); with a direction built without any layer 16/17 weights, all 8 layer-16/17 heads are positive (sum +24 vs null -0.4 +/- 4.8). (2) In the full residual space, A's o_proj moved toward re-emitting what each head's own v_proj reads (mean head z +0.6, about 5 sigma; specific to the matched value matrix; base copy heads +4.4 sigma, suppression heads +1.2 sigma). Copying the in-context guess is what sycophancy needs and what correct answering must suppress, so A is sycophantic. Routing (query/key) changes, led by the rank-1 layer-12 query change, alter where heads look but could not be signed from weights. The main caveat is the assumption that the in-context answer token is the user's guess rather than a listed option.

**Pair 101 evidence:** Full fine-tune with diffuse Adam-sized changes everywhere, so magnitudes are uninformative and only statistics that change sign when A and B are swapped can tell direction. (1) Late attention copies more in A: copy alignment of the OV change in layers 16-17 is positive in 16/16 tests (combined z about 5.7, robust in disjoint coordinate halves). (2) Classifying base heads by how their copy map scales with the final-norm gain (context-token copier versus same-space mover), A's context copiers (17.1, 17.0, 16.0, 11.2) attend more to matching content (aggregate z about +6.3, split-half r = 0.86) and its final suppressor 17.3 less, while B's movers (15.3, 15.0, 14.3) amplify the model's own prediction more (z about -6 to -8); some movers (14.1, 16.2) do not fit this split. (3) The strongest K-composition circuit 10.1->11.2/11.3 favours echoing in A. (4) A GELU gating argument, validated by gate/up/down agreement per unit (r = 0.23-0.66 versus about 0 for shuffled units), shows that early/mid-layer (recall) MLP units serve B's targets and layer 16-17 units serve A's, so B's target is what the base's knowledge computes. Caveats: layers 14-15 move in the opposite direction, the head classification and the MLP reading rest on assumptions, and no single test is decisive.

**Pair 102 evidence:** Built an answer-token subspace S from late down/o_proj differences (consistent across layers, 10-20x chance overlap; early and late layers' differences read it beyond matched controls). Sign-sensitive tests linear in A-B: (1) OV copy of answer tokens inside S is higher in A for L15H0/H2/H3 and L16H1/H2/H3 (z +2 to +7.6 vs profile-matched controls, stable over 27 constructions of S; same sign, weaker, with S built only from attention or only from the L17 MLP) and in all layer-0/1 heads; with open-ended questions the only answer token in the prompt is the guess, so more copying means the guess-trained model. (2) Late-MLP (L15-17) down_proj changes in B align with their existing answer-token output (sign-flip null z about -2 per layer; same sign with independently built S), i.e. B learned to write the stored answer; these MLPs carry the largest answer-space difference. (3) L17H3 readout moves toward B. QK identity-matching effects did not survive controls and were not used.
